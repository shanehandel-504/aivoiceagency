### Volume normalization has no target

Retell's agent API has **no volume-normalization field**. Verified against the live
object and the current API reference. What exists:

- `volume` — agent loudness [0,2]. Not normalization. Left at the baseline `1`.
- `handbook_config.speech_normalization` — **text** normalization (dates/numbers).
  Not audio.

`speech_normalization` was left **OFF** because the same instruction ordered Smart
Matching / AI Disclosure / Scope Boundaries ON and **all other modules OFF**. The
explicit list wins over an inferred mapping. **Shane's call if that was the intent.**

### Method caveat — interruption count is DERIVED

**Retell reports no interruption field** (zero keys matching `/interrupt/` across all
25 raw call objects). A barge-in is counted as a user turn whose first word starts
before the preceding agent turn's last word ends, from word-level timestamps, with a
50ms jitter guard. Class C is assigned from that proxy, not from vendor data.

**Two isolation decisions beyond the brief, both deliberate:**

1. **Its own LLM copy.** Pointing the test agent at the live `llm_id` would make every
   future tuning edit mutate the **live** agent's brain — the same shared-mutable-state
   trap the shared ElevenLabs voice already sets. The prompt is byte-identical either way.
2. **`webhook_url` omitted.** The live agent posts `call_analyzed` into the CRM
   pipeline; a web test firing that would upsert junk into GHL. The webhook has zero
   effect on latency, voice, or turn-taking, so dropping it costs nothing for tuning.

**30/30 verification checks pass on fresh fetch**, including 8 that re-assert the live
rail is untouched.

## §6 · INCIDENTAL CATCHES

- **A field probe silently CREATED an agent.** Retell answers unknown agent fields with
  **201 + silent drop**, not a rejection. The stray agent was deleted and verified 404.
  Consequence: you cannot probe Retell's schema by sending bogus fields — a "success"
  proves nothing about whether the field exists.
- **`POST /publish-agent` was deprecated 2026-07-20.** The working endpoint is
  **`POST /publish-agent-version/{agent_id}`** with an explicit `version`. The legacy
  path fails in a way that is easy to read as "publishing isn't supported."
