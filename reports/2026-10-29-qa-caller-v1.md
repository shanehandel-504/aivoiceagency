## WHAT WAS BUILT

| File | What it does |
|---|---|
| `tools/qa/grade_call.py` | Grades a call id, `--agent <id> --last N`, or `--dir <folder>`. In code: per-turn gap (agent first word − caller last word, overlaps excluded, Phase 0 method), p50 / p95, max gap and its turn, silence prompts, duration, disconnection reason, extracted variables present / empty, greeting byte check, recorded-line notice. Claude Haiku 5.5 with `rubric.md`: every caller question verbatim and whether it was answered before the next ask, re-asked fields, invented facts, dead ends, one question per turn, booked-before-tool, "owner", outcome. A second narrow Haiku pass re-asks each skipped question / invented fact / dead end / re-ask on its own; an item counts only if both passes find it. Writes one JSON per call plus `summary-<label>.md`. `--batch` uses the Batch API. |
| `tools/qa/rubric.md` | The house rules in plain words (R1 answer-then-resume … R11 greeting byte-exact), outcome definitions, and LINE FACTS (true statements that are never findings). Sent word for word to the grader; edit rules here, no code change. |
| `tools/qa/lines.json` | Per-line agent ids (live + Session A's AIC-TEST candidates) and the stored greetings: AIC = n01_p / n01_b static text of flow v15; AVA = the call's own `opening_line` (begin_message is `{{opening_line}}`). |
| `tools/qa/text_caller.py` | Sonnet 5.5 plays a scenario against an agent over Retell's playground endpoint, up to 20 caller turns, transcript saved, then graded. Enumerates every tool the agent can reach from its live config and mocks each one; refuses to run if a node points at a tool it cannot name. Default version = the one bound to the line's public number. |
| `tools/qa/write_scenarios.py` + `tools/qa/scenarios/*.json` | 50 AIC + 20 AVA scripted callers (persona, opening line, 6–10 turns with branches, curveballs, hesitation rules, expected behaviours, must-nots). `aic-001` = the Denver script, verbatim from PASTE-CC-AIC-AGENT-BUILD-v1.1 T1. |
| `tools/qa/_retell.py` · `_claude.py` · `_mask.py` | Retell transport with a hard allowlist (anything else raises READ-ONLY GUARD) · Claude client with a per-request token/dollar ledger, a cross-process lock and the $10 stop · masking applied before anything is saved or sent. |
| `tools/qa/README.md` | The one-line commands (grade a call id · last 20 on an agent · a folder · N scenarios in text). |

## STEP 3 — TEXT CHANNEL FINDING

| Option (docs) | What it is | Fits a conversation-flow VOICE agent? |
|---|---|---|
| `POST /create-chat` + `POST /create-chat-completion` — docs.retellai.com/api-references/create-chat | A chat session on a **chat agent** ("The chat agent to use for the chat"); creates a persisted chat object | Not stated for voice agents; would need a chat-channel twin. Not used. |

| Simulation / test-case API — docs.retellai.com/test/llm-simulation-testing, /api-references/create-test-case-definition | Retell-run simulated user + success criteria, batch tests | Works for agents, but creates persisted test-case definitions and batch-test objects on Retell (writes). Not needed. |

Traps the run hit: unmocked tools **run for real** on the playground ("Calls matching no mock run the real tool"), so
the text caller mocks every tool it finds (0019 v15: `get_open_slots`, `book_slot`, `team_alert`, the TR-CALL
transfer; `end_call` left real — it only ends the session). A text session carries no caller ID: the first smoke run
read back an empty number ("That's . Is that right?"); runs pass `user_number` = 414-555-0142 (reserved fictional range).

**Retell cost of the text runs.** The endpoint returns no cost. Counted: 139 playground requests (2 probe + 14 smoke +
123 scenario); the 10 scenarios produced 1,415 messages of every role, 151 of them agent messages (smoke: 144 / 16).
Retell's pricing page lists GPT 4.1 chat at **$0.015 per AI message** (retellai.com/pricing; no high-priority chat rate
is listed) and its testing-pricing page says text tests bill per message at the model's chat rate. List-price
arithmetic, not a measured charge: 167 agent messages × $0.015 = **$2.51**; Retell's billing page holds the real figure.

## GOTCHAS

1. **Unmocked tools run for real on Retell's playground.** The text caller enumerates every tool from the live config and
   mocks it, and refuses to run on a tool it cannot name. Never point it at an agent with a new tool type without reading
   `enumerate_tools` first.
2. **A text session has no caller ID.** The flow reads `{{user_number}}`; without it the read-back said "That's . Is that
   right?". Pass a reserved 414-555-01xx number.
3. **One broad Haiku pass over-flags.** It counted "I'd like to book a ride" and "Yes." as questions and listed items it had
   itself judged fine. Fixes in the code: an explicit `is_finding` field, a code check that a question carries a "?" or an
   open question opener, and the narrow second pass. Repeatability went to 40 / 41.
4. **The grader does not know today's date or the caller ID** unless told. Both are now code facts in the prompt
   (one false "wrong weekday" and one false "invented phone number" before that).
5. **Masking must be consistent across turns.** "the Pfister Hotel in Milwaukee" masked in the caller's turn but not in
   the agent's read-back looked like an invented place. Places now mask their spoken core too.
6. **Windows appends are not atomic across processes.** Two graders writing the ledger at once overwrote part of a row and
   crashed three runs; a lock file now guards every write. Every result had its row; nothing was lost.
7. **The Bash tool here collapses `\\` in heredocs** — a regex `\b` landed as a backspace byte. Patch files written with the
   Write tool avoid it.
8. **`python -I` hides the user-site `anthropic` package** — run these tools without `-I`.
9. **The PASTE's "about 1.2 s" for the AVA proof call is the line median.** The proof call itself is 2.00 s p50 in both
   Phase 0 and the grader.
10. **Outcome is the least stable field** (39 / 41 repeat). Read outcomes as a guide, skips and timing as the gate.
11. **Two authored flow lines are flagged on every run** ("The live version is configured…your software all set up…" and
    "We'll be tracking your flight."). They need a ruling; the rubric was not bent to hide them.
12. **Grader outputs are not in the repo.** Per-call verdicts and transcripts stay under `ops/tuning/qa/` on the Dell;
    only code, scenarios, this report and the board line are committed.

LESSON: Let code decide everything that is a fact (timing, greeting, date, caller ID) and give the model one narrow
question per finding — a single broad grading pass is too noisy to gate on.
