## Gotchas / notes
- Published Retell versions are **immutable** — flow was fork (`create-agent-version {base_version:32}`) →
  `PATCH update-retell-llm ?version=33` → `PATCH update-agent ?version=33` (title/description + re-assert
  locked voice) → `publish-agent-version {version:33}`. Publishing the agent version publishes the linked LLM too.
- **UTF-8 hazard on Windows:** native Python defaults to cp1252 stdout, which cannot encode the prompt's
  `→` arrows (em-dashes it tolerates). All edits done with `PYTHONUTF8=1` and the PATCH body sent via
  `curl --data-binary @file` (charset=utf-8) to avoid any shell mangling. Verified em-dash/arrow bytes on the wire.
- Owner cell lives in Doppler under the typo key **`OWNER_CELL_OHONE`** and is not E.164 — normalized before dialing.
- The 60s test call primed `first_name=Andy` + `business_type=plumbing` so AVA drives straight to the
  changed close lines (team-CONFIRM + team-success + warm sign-off).
