Per-post checklist

  1. Pick the asset — the CapCut master / reel for this slot.
  2. Caption = one backable result — real booked jobs, receipts, dollars. No invented numbers.
  3. Strip phone numbers + raw URLs from GBP post text (Google flags them).
  4. Cold surface? Sign “— AVA Team.” No personal name.
  5. Scrub the copy — no “sounds human,” never script “I’m AI,” no real client names.
  6. Schedule in GHL Social Planner — 2×/day cadence, Reel 3 first.
  7. Log it — tick the To-Do + note on the HQ board.

Connect GHL Social Planner

  1. GHL → Marketing → Social Planner.
  2. Connect accounts — add each network: Facebook Page, Instagram, TikTok, LinkedIn, X, Google Business.
  3. Authorize — approve in each network’s own OAuth window (do it yourself; never hand off credentials).
  4. Set the queue — posting schedule / time slots for the 2×/day cadence.
  5. Draft → Schedule — watch the first post publish clean before trusting the queue.

Content laws

Always
  • Prove the work — booked jobs, receipts, dollars you can back.
  • Sign cold surfaces “AVA Team.”
  • Show the outcome, not the tech.
Never
  • Say AVA “sounds human.”
  • Script “I’m AI” / out AVA as a bot.
  • Phone numbers or raw URLs inside GBP post text.
  • Real client names, or unverified proof / ROI / testimonials.
  • Forbidden words: “locked / locked in,” and “booked / confirmed / guaranteed” as claims about the service.
Cold outreach signs AVA Team. Never a personal name
